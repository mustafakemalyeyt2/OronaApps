# Katkı Rehberi / Contributing Guidelines

Teşekkürler! Bu projeye katkıda bulunmak istiyorsanız aşağıdaki adımları takip edin.

## Nasıl Katkıda Bulunulur? / How to Contribute
1. Reponun bir kopyasını (fork) alın.  
2. Yeni bir branch açın (`feature/özellik-adı` veya `bugfix/hata-adı`).  
3. Değişikliklerinizi yapın ve test edin.  
4. Açıklayıcı commit mesajları kullanın.  
5. Pull Request (PR) gönderin.  

## Kod Standartları / Code Standards
- Kodunuzun derlenebilir ve çalışabilir olduğundan emin olun.  
- Gerekiyorsa test ekleyin.  
- Açıklayıcı yorumlar yazın.  

## Issue Açma / Opening Issues
- Hata raporlarında: adımlar, beklenen sonuç ve gerçek sonuç açıkça yazılmalı.  
- Özellik isteklerinde: neden gerekli olduğunu ve nasıl çalışmasını istediğinizi belirtin.
