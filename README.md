# README.md

### Turkish/Türkçe:

Uygulamayı indirdiğin için teşekkürler! Uygulamayı kurmak için şu yönergeleri takip et:

## ClickOnce:
1. setup.exe yada .application dosyasını bul ve çalıştır.
2. Ekrandaki yönergeleri takip et ve "Yükle" tuşuna tıkla.
3. Bitti.

## Windows Application Package:
1. İndirdiğin .msix dosyasını bul ve çalıştır.
2. Install'a tıkla.
3. İsteğe bağlı olarak "Launch when ready" onay kutusunu işaretleyebilirsin.
4. Kurulum tamamlandığında "Launch" tuşuna tıkla.
5. Bitti.

*&#9888; Dikkat: .msix kurulumu masaüstü kısayolu eklememektedir. Windows Başlat'da genellikle önerilenler kısmında bulunmaktadır.*

# ENGLISH

Thank you for downloading the application! To install the application, follow these instructions:

## ClickOnce:
1. Find and run the setup.exe or .application file.
2. Follow the on-screen instructions and click "Install".
3. Done.

## Windows Application Package:
1. Find and run the .msix file you downloaded.
2. Click Install.
3. Optionally, you can check the "Launch when ready" checkbox.
4. When the installation is complete, click "Launch".
5. Done.

*&#9888;Caution: The .msix installation does not add a desktop shortcut. It is usually found in the suggested options section of the Windows Start menu.*
